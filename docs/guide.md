# 使用与数据说明

## 安装与后台运行

- 首次安装时可以选择程序目录，默认是 `%LOCALAPPDATA%\Programs\MihomoTraffic`。升级沿用原目录，卸载保留账本。升级或卸载前从托盘退出。若之前从旧便携版开启了开机启动，请在安装版中关闭并重新开启一次。
- 便携版应解压到可写目录。更新时保留程序旁的 `portable.flag` 和 `data`。
- 关闭主窗口后默认在后台采集。可从托盘、再次启动程序或按 `Ctrl + Alt + M` 打开。完全退出可用托盘菜单或 `mihomo-traffic.exe --exit`。

## 检查更新

在 **设置 → 关于** 中可手动检查 GitHub 正式发行版。新版提示出现在「更新内容」旁，关闭后有更高版本才会再次出现。检查频率可选每日、每周、每月或永不，新配置默认每周。选择永不后仍可手动检查。程序在下次运行或唤醒时补查已经到期的更新。

「更新内容」按版本从新到旧显示正式发行记录，并标出当前版本。首次打开会获取历史，也可手动刷新。已缓存的说明可以离线查看。发现新版时，弹窗内的下载入口会按运行方式提供安装包或便携版 ZIP。更新查询使用公开的 GitHub Releases 接口，查询内容与 Mihomo 连接配置和账本独立。

## 统计口径

总量来自 Mihomo 累计计数，从首次采样起记账。应用、域名、出站和来源按约一秒一次的连接快照归属。短连接、断线和休眠可能留下未归属流量或采样缺口。订阅额度来自内核或 Clash客户端 本地缓存，和本机用量独立统计。

部分客户端版本支持在设置中永久调整进程识别，程序会在写入前备份客户端配置。

## 数据与隐私

| 内容 | 默认位置 |
| --- | --- |
| 安装版数据 | `%LOCALAPPDATA%\MihomoTraffic` |
| 便携版数据 | EXE 同目录的 `data` |
| 调试版数据 | 仓库内的 `dev-data` |
| 配置、账本和日志 | 数据目录中的 `config.toml`、`traffic.sqlite3`、`traffic.log` |
| 账本备份 | 系统文档中的 `MihomoTraffic\backups`，便携版使用 `data\backups` |
| CSV | 系统下载目录 |

手动连接的 Secret 由当前 Windows 用户加密保存。把便携目录移到另一台电脑或其他 Windows 账户时，账本可以继续使用，需要重新输入 Secret。账本、备份、日志和 CSV 可能包含应用路径、域名或流量记录，客户端原始配置备份还可能含凭据。分享前请检查文件内容。

概览中的出口 IP 功能会经本机代理请求 IP.SB，查到的公网 IP 会用于查询 IPQuery，部分结果缺失时再查 Proxycheck。控制接口的 Secret 用于本机 Mihomo 请求。

新配置默认保留 90 天的域名、出站和来源分钟明细，并保留 3 天秒级明细。分钟总量、应用汇总、每日汇总和速度摘要长期保留。可以在 **设置 → 数据存储** 调整保留时间或设置容量限制。

数据目录迁移会重启应用并保留源目录，账本恢复会先检查备份并为当前账本创建副本。开发和排障时可用 `--data-dir` 指定独立目录。
